# Shared transfer baselines

The `shared-transfer-baselines` launcher queues one data check, two CUDA recovery probes, 42 source fits, 48 target tasks and a CPU collector. The queue releases each training phase only after the preceding phase succeeds. The collector runs after termination and records failed or missing work. Arrays have up to four concurrent GPU tasks. Each task uses one GPU and five CPUs. The source walltime request is capped by the observed partition limit and checked against the engineering profile. Resubmission preserves existing IDs. Explicit retry after a failed batch reuses compatible completed artifacts and checkpoints.

## Frozen training recipe

The V1 transfer recipe instantiates the shared scientific contract for unconditional B03 and B04 comparisons. It preserves the eight canonical data arrays, shared horizons and test origins, support budgets, three seeds, and source exclusions. Bike and taxi share a source checkpoint for each family and seed because their source exclusions are identical.

B03 is a causal adaptation of the released LLM-UTP architecture. It uses the pinned generic GPT-2 initialization with the two blocks the release executes. Both blocks and the active traffic modules train during source fitting, consistent with the authors' source-stage trainability clarification. The released trend fusion softmax uses the within-window feature axis. The released second channel is replaced with the shared causal prefix mean. The release uses two channels. Here the mask is uniformly observed in admitted complete arrays. B03 retains the release's dependence on node order. B04 uses the admitted 28-block Qwen numerical interface and its existing FP32 projection, spatial encoder, prediction head, and LoRA parameters over a frozen BF16 backbone. Neither baseline uses an author's traffic checkpoint. Both keep dropout disabled throughout this benchmark.

Each source fold uses four seeded eligible episodes per domain sampled without replacement from starts with nonconstant inner fitting support. A source epoch samples one of these episodes per domain in the fixed registry order. An episode has 48 support rows, a reserved 64-origin verification block and a 16-origin suffix. Scale fitting and the chronological 70/30 local comparison stay in source-episode support. The local comparison applies the frozen persistence, ridge and compact recipes. The selected support-validation MAE, floored at one, scales the suffix loss. Each source-validation suffix uses the first 16 validation origins with support confined to earlier source training rows. The support block is the most recent eligible 48-row block ending at least 64 rows before that suffix.

The inner learner fits a fresh bottleneck-32 residual head on detached source embeddings for 200 AdamW updates using normalized absolute loss. It draws batches of eight origins with replacement and uses every node. The source learner uses the ordinary gamma-zero first-order suffix objective. It updates the active source parameters once per 16-origin suffix using two-origin microbatches. AdamW learning rates, weight decay and gradient clipping follow the frozen scientific contract. Mean source-validation normalized MAE selects the checkpoint with patience ten and at most 100 epochs. There is no source learning-rate schedule. Resume restores the model, optimizer, RNG, episode/epoch cursor, and early-stopping state. The CUDA probes reconstruct both source and target learners and require equality after a controlled checkpoint interruption.

The target tasks freeze the source model and fit fresh residual heads from target support alone with the same fixed 200 updates. The saved local selector and predictions come from the verified B01/B02 grid. Support-only scaling and selected family are recorded, and all eligible test origins are scored. Zero and infeasible budgets use persistence and contribute deterministic references. Verification candidate forecasts and hashes are saved without scoring the verification labels. The collector independently scores the frozen test predictions and verifies matched targets.

## Scientific scope

The batch establishes unconditional transfer comparisons and prepares fixed candidate artifacts for the later sequential verifier. Independent S01 sign-off remains required for verification claims. The ECTT objective, mechanism ablations, and certificate evaluation remain separate. Forecasts concern ordered rows because timestamps and sensor provenance remain unverified.
